# Sentence Maker release notes

Current project version: **1.0.0**. These dated development milestones are reconstructed from Git history; they are not separate published version releases.

## October 24, 2026 — Documentation

- Added in-app Release Notes and a source history document.

## October 20, 2026 — Guide and layout

- Expanded the User Guide with sentence endings, failed fragments, keyboard behavior, and storage limitations.
- Improved responsive layouts and guide navigation.

## July–August 2026 — Settings and accessibility

- Added settings save-location controls and automatic settings saving.
- Improved accessibility and UI validation.
- Redesigned the settings interface.

## March–June 2026 — Sentence processing

- Added options for treating other characters as sentence endings.
- Improved sentence editor controls and sentence-breaking settings.
- Improved sentence handling when URLs appear in the text.
