# Sentence Maker (Electron)

Simple desktop app that breaks text into individual sentences.

## Run locally
1. Install dependencies: `npm install`
2. Start the app: `npm start`

## Keyboard shortcut
- Use **Settings** and press a key to assign a shortcut for **Break** (letters/numbers alone are not allowed; symbols and Shift+Shift are blocked).
- Leaving the field blank (or hitting **Clear**) clears the shortcut.
- If you assign Enter/Return, pressing Enter will break the text instead of inserting a blank line.
