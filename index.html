Sentence Maker Help

User Guide

Turn text into organized sentences and make the workspace your own.

01

Break text

Type or paste text into the editor, then choose Break. The editor is replaced with the split output. Copy the result into the document or app where you need it; there is no document save/export workflow. Clear empties the editor.

02

Sentence endings and incomplete text

Settings lets you enable period, semicolon, question mark, exclamation mark, colon, and quote endings, plus custom ending characters. At least one selected ending must occur before Break can run.

Completed sentences are separated; fragments without a selected ending are retained and highlighted for correction. Correct them and run Break again. This is punctuation-based splitting, not a grammar parser.

03

Spacing, ordering, and paste

Insert blank lines between broken sentences is on by default. Sort alphabetically sorts completed sentences A–Z when enabled.

Preserve paste formatting controls rich-text paste, but running Break rebuilds the output as text with line breaks and incomplete-fragment highlighting.

04

Keyboard shortcut

In Settings focus the trigger-key control and press the desired shortcut. Clear or an empty shortcut removes it. A lone letter, number, or symbol is rejected; supported combinations can include two keys and modifiers. Shift+Shift is rejected.

If Enter, Space, or Backspace is assigned, it triggers Break instead of its normal editing action. The hint beneath the editor shows the active shortcut.

05

Settings, information tips, and storage

Settings saves preferences immediately. Configure information tips, hover/focus behavior, click pinning, outside-click closing, and delay there. Browse changes the desktop settings folder; Reset to Default returns its standard location.

Reset Settings restores built-in preferences. The writable settings.json defaults to Desktop and a settings-location.json pointer in app data remembers its folder. These files save preferences, not your editor text. Copy needed text before closing.
